# Helechron 应用备案（App ICP 备案）指南

> 适用对象：Helechron（鸿蒙包名 `top.celechron.helechron`，v0.1.7，Flutter/ArkTS 多端）
> 法规依据：工信部《关于开展移动互联网应用程序备案工作的通知》（2023 年起，APP 未备案不得上架、分发、提供下载服务）

---

## 一、先弄清楚：向谁备案

App 备案**不是**去工信部官网自己填，而是通过你的"网络接入服务商"（即你上架的渠道）提交，**全程免费**。按发布平台分别走：

| 发布渠道 | 备案入口 | 说明 |
|---|---|---|
| 鸿蒙 AppGallery | AppGallery Connect（AGC）→ 你的应用 → "ICP 备案"服务 | 主渠道。华为做初核，再转省通信管理局 |
| iOS 中国区 App Store | App Store Connect → 协议/备案区域（Apple 作为接入服务商） | 分区上架时也需要 |
| 安卓各商店（华为应用市场/小米/OPPO/vivo/应用宝） | 各商店开发者后台内嵌的备案通道 | 一个应用通常可在多家渠道分别备案，备案号同一体系 |
| 直接分发 APK / .hap（不走商店） | 仍需选一家接入服务商（如服务器所在云厂商，或任一合作渠道） | 用 GitHub Actions 产物直接发给同学安装也属于"分发"，同样受备案约束 |

**建议**：先在鸿蒙 AGC 走通主流程拿到备案号，其他渠道填同一个号即可。

## 二、备案前置条件（缺一不可）

1. **开发者账号实名认证**
   - 个人主体：华为开发者联盟"个人开发者"实名认证（身份证 + 人脸），当日可过。
   - 企业主体：营业执照 + 法人认证（如果以实验室/公司名义，走这条）。
2. **在 AGC 中创建应用**：包名 `top.celechron.helechron`、应用名称、图标就绪。
3. **可公开访问的隐私政策 URL**：已生成 `docs/privacy.html`，部署后可用的默认地址是 `https://kepler16f.github.io/Helechron/privacy.html`（见 `lib/utils/legal_links.dart`）。注意 GitHub Pages 国内访问不稳定，建议绑定自己的已备案域名，或同时准备备用镜像；商店审核要求点开即达。
4. **软件著作权（上架必需，备案本身不强求）**：
   - 中国版权保护中心登记：免费，但排队约 2 个月。
   - 电子版权认证（版权保护中心/华为合作渠道）：几百元，1~5 个工作日，上架普遍认可。
   - 软著登记主体必须与备案主体**一致**（个人就对个人）。

## 三、备案表单怎么填（Helechron 定制草稿）

**主办者信息**
- 主体类别：个人 / 企业（决定后续所有材料）
- 名称、证件号（身份证/统一社会信用代码）、联系方式、应急电话、证件地址、通讯地址（省市区+详细门牌）

**应用信息**
- 应用名称：Helechron（各渠道、软著、商店页必须完全一致；Android `android:label` 已统一为 Helechron）
- 包名：`top.celechron.helechron`（iOS 填 Bundle ID；多平台可在同一备案号下分别登记各端包名）
- App 图标：上传与安装包一致的 icon
- 服务类别/功能分类：选择"教育-课程/日程工具"或"实用工具"（工信部分类目录内选最贴近的）
- 内容类别：可描述为"个人课程表、日程与 DDL 管理工具，数据本地存储"
- 备注/主要功能简述：查课表、成绩查询、考试与作业提醒、校园卡付款码展示、系统日历同步、桌面小组件；**强调不运营后端、数据全在用户设备本地**。

**网络接入与域名**
- 接入服务商：华为（鸿蒙端）
- 域名一栏：**只填由你（主办者）运营、为 App 提供后台服务的域名**。
  - `*.zju.edu.cn`、`api.github.com`、`uri.amap.com` 等是第三方系统，不填。
  - ⚠️ 关键决策点：`celechron.top`（含 `api.celechron.top` 版本检查、`calendar.celechron.top` 校历配置）如果**由你运营**，必须先把该域名注册实名 + 完成域名 ICP 备案，再在 App 备案中申报；如果域名归上游项目/他人运营，需在表单"是否存在自建服务"如实填"无"，并考虑把这两个服务改为静态托管或由上游方备案。
- 服务器 IP/接入地：无自建服务器则按渠道指引选"无"。

**核验环节**：个人主体一般需在线人脸核验 + 电子承诺书签名；企业主体需负责人核验。

## 四、流程与时间线

```
实名认证 → 创建应用/填资料 → 提交渠道初核（1~3 个工作日）
→ 渠道转报省通管局（法定 ≤20 个工作日，实际多数 1~2 周）
→ 短信收到备案号 → 回填 AGC 备案信息 → 商店上架审核
```

拿到备案号后还需：
1. 在 AGC 应用基本信息里关联备案号，之后才能通过上架审核。
2. **应用内展示备案号**：按工信部要求，在"关于"页（或设置页）显示 ICP 备案号。设置页已支持通过 `--dart-define=ICP_FILING_NUMBER=...` 注入并展示，等号到手后重新构建即可。
3. 备案信息变更（改名、换包名、隐私政策大改、主体变更）须在 30 日内通过原渠道做变更备案。

## 五、Helechron 特有风险点（备案+上架审核都可能踩）

1. **"浙江大学"品牌元素**：应用名、图标、商店宣传图不要出现"浙大/浙江大学"字样或校徽；隐私政策与用户协议已声明非官方，保持并在商店"应用介绍"里也写明。审核被质询时以该声明答复。
2. **校园卡付款码功能**：属泛支付/二维码展示，部分商店会重点问询。准备好说明：仅展示用户本人账户付款码、不提供支付清算、不传输凭据到任何服务器。审核敏感期可先隐藏该功能入口，备案通过后再放开。
3. **`calendar.celechron.top` 走 HTTP 明文**：隐私政策里已如实披露，但工信部/App 隐私合规检测对明文传输敏感，建议尽快上 HTTPS（该配置改为只读 JSON，成本低）。
4. **隐私政策与 consent 流程**：`lib/page/consent_page.dart` + 版本号机制（`privacyPolicyVersion`）已具备，这是商店审核加分项；确保商店链接的在线版与离线 txt 内容一致。
5. **无统计/广告 SDK**：这是过审优势，隐私申报（华为的"隐私标签"问卷）时如实全勾"不收集"。

## 六、材料清单速查

**个人主体**：身份证正反面照片、本人手机号+邮箱、人脸核验、应急联系人（不得为本人）、软著证书（上架用）、承诺书（平台内电子签）。
**企业主体**：营业执照、法人及主体负责人身份证、授权委托书、真实性责任书（盖章）、域名证书（如有）。

## 七、建议执行顺序（最快上线路径）

1. 今天：华为开发者联盟个人实名认证；确认 `celechron.top` 归属与备案状态。
2. 本周：申请电子版权认证（名称=Helechron，主体=你）；Android label 已统一为 Helechron；隐私政策换到稳定可访问的 URL。
3. 认证下来后：AGC 创建应用 → 提交 App 备案 → 等 1~2 周。
4. 备案号到手：回填 AGC + 应用"关于"页展示备案号 → 提交上架审核（首次建议隐藏付款码入口）。
5. iOS/安卓渠道：用同一备案号在各平台后台登记即可，无需重复工信部审批。
