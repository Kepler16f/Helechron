Helechron

课程表 · 日程 · DDL · 成绩

关于

Helechron 是面向浙江大学学生的第三方开源课程表与时间管理工具，支持 HarmonyOS NEXT 与 Android。

日程一览、课表查看、DDL 助手、成绩查询、校园卡付款码、系统日历同步与桌面小组件。

隐私与协议

账号密码、课表、成绩等数据仅保存在你的设备本地；本应用不运营收集这些信息的服务器，未接入广告或统计分析 SDK。
