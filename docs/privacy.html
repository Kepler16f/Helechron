Helechron 隐私政策

更新日期：2026年10月26日

生效日期：2026年10月26日

版本：1.0

【特别说明】

Helechron（以下简称“本应用”）是由 Helechron 开源项目维护者（以下简称“我们”）开发和维护的第三方开源课程表与时间管理工具。本应用不是浙江大学官方应用，与浙江大学及其任何附属机构不存在隶属、授权、合作或背书关系。本应用所展示的课程、成绩、考试、作业、校园卡等信息均来自你本人登录的学校系统，仅供参考，请以学校官方系统为准。

我们深知个人信息对你的重要性，将按照《中华人民共和国个人信息保护法》《中华人民共和国网络安全法》《中华人民共和国数据安全法》等法律法规的要求，遵循合法、正当、必要和诚信原则处理你的个人信息。请在使用本应用前仔细阅读本政策；如果你不同意本政策，请不要使用本应用。

一、我们处理哪些信息

1. 学校账号信息：你在“设置—登录”中主动填写的浙江大学统一身份认证账号（学号/工号）和密码。该信息仅用于向浙江大学相关系统发起登录请求，以获取你本人有权访问的数据。账号和密码仅保存在你的设备本地。

2. 学习与校园数据：课程表、成绩、考试安排、作业与截止日期、培养方案、素质拓展、校园卡付款码等。上述数据由你登录后从学校系统获取，并保存在你的设备本地，用于展示、提醒和小组件。

3. 本地设置与诊断日志：主题、提醒开关、底栏样式、刷新策略、代理设置等偏好；诊断日志用于排查崩溃和刷新失败，可能包含时间、模块名、错误信息和账号标识。诊断日志仅保存在本地，除非你主动导出或分享。

4. 设备与权限相关信息：网络状态、系统日历读写权限、通知权限、文件选择结果、后台刷新状态。我们不会读取你的通讯录、短信、位置、相册、麦克风或摄像头。

5. 我们不会收集：广告标识符、IMEI、MAC 地址、精确位置、通讯录、应用安装列表、剪贴板内容。本应用未接入广告、统计分析、用户画像或崩溃上报类第三方 SDK。

二、我们如何存储信息

1. 本应用的数据保存在你的设备本地，主要使用 Hive 数据库和应用私有目录。账号密码、校园卡凭据等敏感信息保存在应用私有存储中，受 HarmonyOS 应用沙箱、Android 应用私有目录等系统机制保护。

2. 我们目前未对本地 Hive 数据库进行额外的应用层加密。请妥善保管你的设备，避免在公共设备上登录，并在使用完毕后退出登录。

3. 保存期限：上述信息保存至你退出登录、清除应用数据或卸载本应用。卸载应用后，本地数据将随应用数据一并删除。

4. 我们不会将你的账号密码、课表、成绩、校园卡数据上传至我们运营的服务器。我们目前不运营收集上述信息的后端服务。

三、信息如何对外提供

为实现功能，本应用会以你的身份直接访问以下第三方系统，相关请求受其运营方的隐私政策约束：

1. 浙江大学相关系统：zjuam.zju.edu.cn（统一身份认证）、courses.zju.edu.cn（学在浙大）、eta.zju.edu.cn（三全育人）、zdbk.zju.edu.cn（教务）、yjsy.zju.edu.cn（研究生院）、elife.zju.edu.cn、classroom.zju.edu.cn、sztz.zju.edu.cn 等。

2. 版本检查：api.celechron.top/checkUpdate?platform=ohos，仅发送平台标识，不发送账号、设备标识或其他个人信息。

3. 校历配置：calendar.celechron.top，用于获取校历配置，不包含个人信息。该接口目前使用 HTTP 明文传输，我们会在条件允许时推动其升级为 HTTPS。

4. 开源项目信息：api.github.com，仅在你打开“关于”页面时用于获取贡献者列表。

5. 外部链接：当你主动点击地址或帮助链接时，可能跳转至高德地图、GitHub 等第三方应用或网站。

6. 分享与导出：当你主动使用分享、导出 iCal 等功能时，相关数据会交由你选择的第三方应用处理。

除上述为实现功能所必需、法律法规另有规定或经你单独同意的情形外，我们不会共享、转让或公开披露你的个人信息。我们不会出售你的个人信息。

四、系统权限说明

1. 网络权限：登录学校系统、刷新课表与成绩、检查版本。

2. 日历读写权限：仅在你开启“同步到系统日历”后，用于创建、更新和删除课程日程。

3. 通知权限：用于成绩变动、DDL 截止和课程提醒。

4. 开机自启/后台刷新：Android 的开机广播与后台任务、HarmonyOS 的代理提醒，用于恢复定时提醒。

5. 文件选择：仅在你主动选择作业附件时，通过系统文件选择器访问你选中的文件。

以上权限均可拒绝或随时在系统设置中关闭；拒绝后对应功能可能不可用，但不影响其他功能。

五、第三方组件与 SDK

1. Flutter 框架及开源组件（Hive、table_calendar、qr_flutter、crypto、timezone 等）用于本地功能实现，不收集个人信息。

2. device_calendar、flutter_local_notifications、workmanager、file_picker、share_plus、url_launcher、app_links 等插件用于调用系统能力。

3. HarmonyOS 端使用系统日历、通知、代理提醒、小组件等系统 Kit，由系统提供能力。

4. 本应用未集成广告、统计分析、社交登录、推送营销类第三方 SDK。

六、数据安全

1. 我们采取系统沙箱隔离、最小权限、HTTPS 传输（学校个别系统或校历配置接口可能使用 HTTP）等措施保护你的信息。

2. 由于本应用为开源非商业项目，无法承诺绝对安全。如发现安全漏洞，请通过下述联系方式告知我们。

3. 如发生个人信息安全事件，我们将通过项目仓库或应用内公告告知你，并说明事件情况、可能影响和补救措施。

七、你的权利

1. 查阅与更正：你可以在应用内查看课表、成绩等信息，并在设置中修改相关配置。

2. 删除：退出登录会清除账号密码和登录态；清除应用数据或卸载应用会删除全部本地数据。

3. 撤回同意：你可以在系统设置中清除应用数据，或卸载本应用以撤回同意。撤回不影响撤回前基于同意已进行的处理。

4. 注销：本应用没有独立账号体系，无需注册；退出登录即停止使用学校账号。

5. 响应：你可以通过 GitHub Issues 联系我们，我们将在 15 个工作日内答复。

八、未成年人保护

本应用面向高校学生。若你未满 14 周岁，请在监护人陪同下阅读本政策，并在取得监护人同意后使用。我们不会主动收集年龄信息。

九、政策更新

我们可能适时更新本政策。更新后会在应用内展示；涉及处理目的、方式或信息种类等重大变更时，我们会再次征得你的同意。
