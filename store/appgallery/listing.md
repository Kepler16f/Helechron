## 2. 应用介绍（长文本）

```text
Helechron 是一款面向浙江大学学生的第三方开源课程表与时间管理工具，非浙江大学官方应用，与浙江大学及其附属机构无隶属、授权或合作关系。

【日程与课表】
用“接下来”时间流查看即将上课、作业截止、考试等事件；支持周课表与日历视图、学期切换、单双周与调课展示，课程时间、地点和教师信息一目了然。

【任务与学业】
集中管理作业与 DDL，支持完成状态与提醒；提供课程列表、成绩查询、考试安排与 GPA 模拟，方便了解学习进度。

【校园与桌面】
支持展示本人校园卡付款码（仅展示，不提供支付服务），并可从桌面小组件快捷打开；课程表可同步到系统日历，另提供桌面课程倒计时小组件。

【隐私与数据】
账号密码、课表、成绩等仅保存在你的设备本地，不上传到开发者服务器；不接入广告、统计或用户画像 SDK。首次启动会展示隐私政策，同意后才会读取账号和联网；可随时退出登录、清除应用数据或卸载应用删除本地信息。

【其他】
支持深色模式、iCal 导入导出、备份与恢复。应用免费、无广告、无内购，基于 GPL-3.0 协议开源：https://github.com/Kepler16f/Helechron

课程、成绩、考试等信息仅供参考，请以学校官方系统为准。
```

## 5. 权限用途说明

### HarmonyOS

| 权限 | 用途 | 触发时机 |
|---|---|---|
| `ohos.permission.INTERNET` | 登录学校系统、刷新课表/成绩、检查版本 | 登录后、刷新时 |
| `ohos.permission.GET_NETWORK_INFO` | 判断网络状态，选择直连或代理 | 启动/刷新时 |
| `ohos.permission.PUBLISH_AGENT_REMINDER` | 成绩变动、DDL、课程提醒 | 用户开启提醒后 |
| `ohos.permission.READ_CALENDAR` | 读取日历以避免重复日程 | 用户开启日历同步后 |
| `ohos.permission.WRITE_CALENDAR` | 将课程写入系统日历 | 用户开启日历同步后 |

### Android

| 权限 | 用途 | 触发时机 |
|---|---|---|
| `INTERNET` | 登录学校系统、刷新数据、检查版本 | 登录后、刷新时 |
| `READ_CALENDAR` | 读取日历以避免重复日程 | 用户开启日历同步后 |
| `WRITE_CALENDAR` | 将课程写入系统日历 | 用户开启日历同步后 |
| `POST_NOTIFICATIONS` | 成绩变动、DDL、课程提醒 | 用户开启提醒后 |
| `RECEIVE_BOOT_COMPLETED` | 重启后恢复定时提醒 | 系统重启后 |

文件选择使用系统文件选择器，不申请广泛存储权限。应用不申请位置、通讯录、相机、麦克风、短信权限。

## 6. 隐私标签 / 数据安全表单

| 信息类型 | 是否处理 | 存储位置 | 是否共享 |
|---|---|---|---|
| 学校账号（账号、密码） | 是 | 设备本地应用私有目录 | 否 |
| 课程表、成绩、考试、作业等教育信息 | 是 | 设备本地 | 否 |
| 系统日历 | 是（用户开启同步后） | 设备本地/系统日历 | 否 |
| 用户选择的文件（作业附件） | 是（用户主动选择） | 设备本地 | 否 |
| 诊断日志 | 是 | 设备本地 | 否（除非用户主动导出/分享） |
| 位置、通讯录、短信、相册、麦克风、摄像头 | 否 | — | 否 |
| 广告标识符、IMEI、MAC、应用列表 | 否 | — | 否 |

补充说明：

- 本应用没有自建用户账号体系，不向开发者服务器上传上述数据。
- 为实现功能，应用会以用户身份直接访问浙江大学相关系统（zjuam、courses、eta、zdbk、yjsy、elife、classroom、sztz 等）以及 `api.celechron.top`（版本检查）、`calendar.celechron.top`（校历配置）、`api.github.com`（贡献者列表）。
- 校历配置接口目前为 HTTP 明文；学校个别系统也可能使用 HTTP。隐私政策已如实披露。
- 数据删除：退出登录清除账号密码与登录态；清除应用数据或卸载应用删除全部本地数据。
- 第三方 SDK：无广告、统计分析、用户画像、社交登录、崩溃上报 SDK。使用的 Flutter 开源库与系统 Kit 见隐私政策。
